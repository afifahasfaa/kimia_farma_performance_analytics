## 📝 Project Overview
Kimia Farma Performance Analytics involves creating a performance analysis dashboard for Kimia Farma (covering the years 2020–2023) using Google Looker Studio. The dashboard is based on “Tabel Analisa” generated by merging four datasets in BigQuery.
